# QuizeLive Play

Экран зала `/tv` и пульт `/join`. Оба говорят с game-server по WebSocket.

## Локально

В одном терминале API, в другом game-server, в третьем этот проект:

```bash
cd quizelive-backend && go run ./cmd/admin-api start
cd quizelive-backend && go run ./cmd/game-server
cd quizelive-play && yarn install && yarn dev
```

Игра открывается на `http://127.0.0.1:5175`. Vite проксирует `/ws` на `127.0.0.1:8087`.

1. В админке опубликуйте викторину и выпустите токен ведущего.
2. Откройте `/tv`, вставьте токен. На экране появится код комнаты.
3. На телефоне откройте `/join`, введите код и имя.
4. На экране нажмите «Начать».

Токен ведущего живёт около двух минут и нужен только чтобы открыть комнату. Дальше экран переподключается своим ключом комнаты.
